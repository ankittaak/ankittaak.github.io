# Ankit Taak Portfolio — milestone 1

Responsive portfolio starter with the site header, mobile navigation, hero section, expertise list, and contact placeholder.

## Files
- `index.html` — page structure and accessible content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and footer year
- `assets/at-logo.png` — supplied AT logo with dark background removed
- `assets/ankit-portrait.jpg` — supplied portrait

## Preview
Open `index.html` in a browser. The Google Fonts import needs an internet connection; system fallbacks are included.

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload all files and folders in this project (keep the `assets` folder).
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Wait for the deployment and open `https://YOUR-USERNAME.github.io`.
